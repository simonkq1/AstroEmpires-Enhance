# Astro Empires Enhance

为 Astro Empires 的 **Borealis 服务器**提供战报 BBCode 复制与分析、AEBits 导入、舰队资料复制及抵达时间预测。脚本界面支持**简体中文与英文**，战报分析也支持这两种语言。

## 安装与首次使用

1. 在浏览器中安装并启用 Tampermonkey。
2. 在本脚本的 Greasy Fork 页面安装脚本，并确认 Tampermonkey 的安装提示。
3. 打开或刷新 [Borealis](https://borealis.astroempires.com/)，在首次语言选择窗口中选择“简体中文”或“English”，再点击“保存 / Save”。

选择“稍后 / Later”或按 Esc，会在本页暂用英文，下次载入时再次询问。脚本目前仅在 Borealis 启用。

## 右下角功能菜单

点击右下角圆形上箭头按钮可展开功能菜单。

- **分析 BBCode**：粘贴战报，查看攻守双方的科技分析结果。
- **设置**：在“显示”中切换界面语言并保存，当前页面会立即更新。取消会放弃未保存的选择。
- **说明**：打开居中的使用说明窗口。点击“关闭”或按 Esc 返回功能菜单。

分析面板的关闭按钮或 Esc 会返回功能菜单，菜单中再按 Esc 可全部收起。切换菜单、打开设置或说明时，已输入的战报和分析结果会保留至离开页面。

## 复制战报 BBCode

在消息页（`messages.aspx`）、公会面板（`board.aspx`）与战斗页（`combat.aspx`），每份完整战报下方会出现“**复制战报 BBCode**”。

点击后可复制该份战报的信息、链接、双方兵力与战果，保留来源页面的语言。若无法访问剪贴板，脚本会显示文本框，供手动选择并复制。

请使用此功能取得供分析的 BBCode，避免直接复制游戏表格造成格式缺失。

## 分析战报与导入 AEBits

1. 从右下角菜单打开“分析 BBCode”。
2. 粘贴战报 BBCode，点击“分析”。
3. 查看双方已确认的科技等级，以及“待确认”字段的原因。
4. 点击“**导入 AEBits 战斗模拟器**”，在新标签页打开模拟器。

支持完整战报，也支持只有攻守方标题与 `[code]` 兵力表格的 BBCode。请保留舰船、初始数量、战后数量、攻击、装甲、护盾六栏，以 Tab 或连续空白分隔。

导入使用双方的**初始兵力**，保留小数兵力和战后全灭单位；仅有一方资料时只导入该方。已确认的科技与明列加成一并带入，游戏版本为 5。模拟器的中英文语言跟随脚本设置。

科技推算依赖可用数值与加成资料。资料不足、基地防御受损或数值矛盾时，无法确认的科技会省略，请在模拟器中手动检查。仅有兵力表格时仍可导入有效兵力，但可能无法确认部分科技。

攻方没有指挥中心和指挥官加成，仅有兵力表格也可推算有有效数值的武器科技。守方加成则依战报信息判定，资料不足时仍会提示待确认。

未识别单位、初始数量无效或兵力列不完整会阻止导入，界面会提示对应原因。修改输入会清除旧结果，请修正后重新分析。

## 舰队详情与战斗页工具

### 舰队详情

打开带有有效舰队编号和舰船资料的舰队详情页，舰船表下方会显示以下按钮。

- **复制舰队资料**：选择简体中文或英文，每行输出“舰种 + Tab + 数量”，方便粘贴到表格或其他工具。
- **AEBits 战斗计算器**：选择攻方或守方，在新标签页导入舰船与游戏版本 5。此页面不提供科技数据，请在模拟器中填写。

### 战斗页

战斗页有可用兵力资料时，可使用相同的复制和 AEBits 按钮。

- 复制时可选择攻方或守方，以及简体中文或英文；守方资料包含页面列出的防御设施。
- AEBits 会导入双方初始兵力、已确认科技与列出的加成。需要手动确认的字段会显示在按钮下方。

复制输出语言可独立于脚本界面语言选择。舰队资料复制失败时，也会提供手动复制文本框。

## 舰队移动抵达时间预测

在舰队移动页（`fleet.aspx`，带有效的 `fleet` 编号及 `view=move`），选择目的地并设置舰船与速度。游戏算出航行时间后，表格下方会显示“**预计到达**”，每秒更新，表示如果现在出发的抵达时间。

- **服务器时间**：从游戏页首的服务器时钟起算，以 GMT+1 显示。无法读取有效时钟时显示“无法取得”。
- **本地时间**：独立从设备当前时间起算，使用设备时区，并按抵达时刻的夏令时间显示。

航行时间无效时会清除旧预测。预测功能只显示时间，不会派遣舰队。

## 基地经济与基地数量

在基地页的掠夺价值下方，可查看预计所有者基地数量。只有资料能按 v5 规则对应正整数时才显示数量；占领中、近期掠夺或资料无法确认时显示原因。不明生物 / Drekons 与联合殖民地 / United Colonies 为 NPC，不推算玩家基地数量。

在攻击基地的战斗页，脚本会读取一次同服目标基地页面，最多等待 5 秒，再启用 AEBits 按钮，复制功能仍可使用。显示 `X/Y` 时，X 导入为收入、Y 导入为经济；只显示 `Y` 时，收入与经济均为 Y。例如 `89/126` 会带入收入 89、经济 126。

Drekons / 不明生物的基地数量固定导入为 8；United Colonies / 联合殖民地省略基地数量，保留收入与经济。其他数量未知时也保留收入与经济；读取失败时三项皆省略，仍导入兵力和科技。请在模拟器手动确认上次掠夺时间及未导入的基地数量。这项读取不会触发攻击或掠夺。

## 数据与外部资源

- 语言设置保存在浏览器的 Borealis 网站存储空间中。保存失败时，所选语言仍应用于本页，并显示提示。
- 战报转换与分析在当前页面内进行，粘贴内容不会由脚本保存到浏览器存储空间，离开页面后不会保留。
- 点击 AEBits 导入时，兵力、可确认的科技和加成会放入新标签页的网址参数中，发送至 AEBits。
- 脚本通过 `@require` 从 jsDelivr 加载 Vue，并从 Google Fonts 加载 Material Icons 图标字体。字体加载失败时，菜单按钮仍可使用箭头与关闭符号。
